ANPR

Automatic License Plate Recognition System

This project is an AI-powered Automatic Number Plate Recognition (ANPR) system. Instead of real-time video, users can upload a vehicle image, and the system will detect and recognize the license plate. Behind the scenes, it uses smart image processing and AI models to clean up the image, find the plate, and read the characters. Once detected, it checks a sample database to show the vehicle's details like registration info and alerts if it's wanted, stolen, or unknown.
